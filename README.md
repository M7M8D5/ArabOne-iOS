#  الحل مؤكد رسميًا على iOS 17.5+ (تقرير WebKit 233419): يكفي وجود
#  UIBackgroundModes = audio في Info.plist — وهو مفعّل هنا بالفعل.
#
#  ## كيف يبنى (بلا جهاز Mac)
#  1. ارفع هذا المجلد كاملًا لمستودع GitHub جديد باسم ArabOne-iOS
#  2. افتح تبويب Actions في المستودع — ستجد "ArabOne iOS Build"
#  3. اضغطه ثم "Run workflow" → Run
#  4. بعد 3-5 دقائق، افتح البناء الأخير → Artifacts → ArabOne-iOS-IPA
#  5. يطلع لك ملف ArabOne-unsigned.ipa — هذا الذي ترسله للاعبين
#
#  ## كيف يثبته اللاعب
#  حسب أداة اللاعب نفسه:
#   • TrollStore: يثبت مباشرة — دائم بلا انتهاء
#   • ESign / Scarlet: يوقع الملف بشهادته ثم يثبت — 7 أيام ويعيد
#   • Sideloadly (مع جهاز كمبيوتر): يوقع بآبل ID — 7 أيام ويعيد
#
#  ملاحظة: IPA غير موقّع عمدًا — كل لاعب يوقعه بأداته، فلا تحتاج أنت
#  حساب مطور ولا جهاز ماك إطلاقًا.
